# OASIS Project Page

This repository hosts the static project page for:

**OASIS: Observation-Action Space Alignment via SE(3) Trajectory Prediction for Robotic Manipulation**

The page summarizes the method, simulation and real-world results, ablations, and demo videos.

## Structure

- `index.html`: project page entry point
- `static/css/`: page styles
- `static/js/`: minimal navigation script
- `static/images/paper/`: web-ready figures exported from the latest paper draft
- `static/videos/`: simulation and real-world demo videos used by the page

The latest paper source and raw supplementary material are kept locally under:

- `OASIS_arxiv202605/`
- `supplementary material/`

Those two directories are ignored by Git because they are source/raw working materials rather than website assets.
